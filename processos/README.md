## Do papel ao sistema

```
processo CAR físico
   -> digitalização (PDF)
   -> autuação no E-Docs
        -> despacho para o grupo "ifes campus <campus> - integracar"
             -> integracar-dashboard (acompanhamento dos processos)
   -> integracar-gestao (envio do PDF)
        -> extração automática de campos (integracar-backend-extrator / integracar-ocr-extrator)
        -> revisão campo a campo pelo bolsista
```

A autuação e o despacho para o grupo IntegraCAR do campus são o que faz o
processo aparecer no [dashboard](../dashboard/README.md): o painel classifica
como IntegraCAR o processo cuja custódia atual é um desses grupos.
